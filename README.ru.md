# SwiDJ — музыка и обработка аудио в Telegram

[English](README.md) · [Архитектура](docs/ARCHITECTURE.md)

SwiDJ — проект для портфолио: поиск музыки, личная библиотека, обработка аудио и скачивание доступных публичных видео в одном Telegram-боте. Интерфейс работает на русском и английском.

## Возможности

- Поиск песни по названию или словам; локальная расшифровка голосового для поиска.
- Аудио YouTube и SoundCloud.
- Ссылки Spotify, Apple Music и Яндекс Музыки: определение песни и поиск соответствующей полной записи на YouTube. При точном совпадении названия и исполнителя загрузка автоматическая.
- Видео YouTube, TikTok, Instagram/Reels.
- Избранное, плейлисты и сохранение собственных аудиофайлов.
- Обрезка, смена формата, эффекты, ускорение, реверс, лупы и рингтоны.
- Переключение языка, отмена операций, повторы после ошибок и панель владельца.

Загрузка из подписочных каталогов не извлекает защищённые оригиналы. Неоднозначные совпадения требуют выбора записи. Доступность внешних источников зависит от региона и изменений платформ.

## Запуск

Нужны Docker с Compose и собственный Telegram-токен от @BotFather.

1. Скопируйте `.env.example` в `.env`.
2. Заполните `TELEGRAM_TOKEN`. Для поиска по каталогу/словам можно добавить `GENIUS_TOKEN`.
3. Выполните:

```sh
docker compose up --build -d
docker compose logs --tail 50 bot
```

В боте отправьте `/start`; язык меняется через `/language`. Остановка: `docker compose stop`.

Первый запуск может потребовать времени на сборку и загрузку локальной модели речи. Платные API по умолчанию выключены. Нельзя одновременно запускать два polling-процесса с одним токеном.

## Проверки и ограничения

Пройдены 158 офлайн-тестов: обработчики Telegram, два языка, изоляция пользователей, плейлисты, отмена, повторы и очистка файлов. Инструкции проверки находятся в [английском README](README.md#verification).

Это работающий прототип для портфолио, созданный итеративно с помощью AI. Он не является обещанием круглосуточного публичного сервиса. Mini App, платежи и надёжное распознавание напевания пока не реализованы. Музыкальные платные API не включены.

Используйте только материалы, на обработку которых у вас есть разрешение. Закрытые публикации могут быть недоступны; лимит выходного видео — 49 МиБ. Не публикуйте токены, cookies, пользовательские данные и резервные копии.
