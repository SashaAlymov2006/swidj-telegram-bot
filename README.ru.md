# SwiDJ — музыка и обработка аудио в Telegram

[English](README.md) · [Архитектура](docs/ARCHITECTURE.md)

SwiDJ — проект для портфолио: поиск музыки, личная библиотека, обработка аудио и скачивание доступных публичных видео в одном Telegram-боте. Интерфейс работает на русском и английском.

## Возможности

- Поиск песни по названию или словам; локальная расшифровка голосового для поиска.
- Аудио YouTube и SoundCloud.
- Ссылки Spotify, Apple Music и Яндекс Музыки: определение песни и поиск соответствующей полной записи на YouTube. При точном совпадении названия и исполнителя загрузка автоматическая.
- Видео YouTube, TikTok, Instagram/Reels.
- Избранное, плейлисты и сохранение собственных аудиофайлов.
- Импорт плейлистов и альбомов: ссылка или список песен → предпросмотр → своя коллекция → выбор аудиоверсии при открытии трека. В Mini App: «Моя музыка → Импорт плейлиста»; в боте — ссылка или `/import`.
- Обрезка, смена формата, эффекты, регулировка баса с прослушиванием, ускорение, реверс, лупы и рингтоны.
- DJ-комната в Mini App: две деки, волна и оценка ритма, независимые тон и скорость, петли по тактам, фильтр, убирание баса и уход эхом. Проекты сетов сохраняют треки и настройки; готовый сет можно записать в MP3.
- Переключение языка, отмена операций, повторы после ошибок и панель владельца.
- Резерв аудио: копия VPS/Telegram, основной источник, совпадение SoundCloud, затем Jamendo. Личные файлы изолированы от общего кэша.

Загрузка из подписочных каталогов не извлекает защищённые оригиналы. Неоднозначные совпадения требуют выбора записи. Доступность внешних источников зависит от региона и изменений платформ.

## Запуск

Нужны Docker с Compose и собственный Telegram-токен от @BotFather.

1. Скопируйте `.env.example` в `.env`.
2. Заполните `TELEGRAM_TOKEN`. Для поиска по каталогу/словам можно добавить `GENIUS_TOKEN`.
3. Выполните:

```sh
docker compose up --build -d
docker compose logs --tail 50 bot
```

В боте отправьте `/start`; язык меняется через `/language`. Остановка: `docker compose stop`.

Первый запуск может потребовать времени на сборку и загрузку локальной модели речи. Платные API по умолчанию выключены. Нельзя одновременно запускать два polling-процесса с одним токеном.

## Проверки и ограничения

Mini App дополняет бота: плеер, поиск, общая библиотека и плейлисты, студия и DJ-комната. После локального запуска Docker откройте http://127.0.0.1:8765 — это деморежим с оригинальными инструментальными примерами. Доступ к настоящей библиотеке требует проверенного входа Telegram и HTTPS-адреса. Бот и Mini App развёрнуты на VPS разработчика. [Подключение и ограничения](MINIAPP.md), [устройство DJ-комнаты](deploy/DJ_ROOM.md).

Пройдены 325 офлайн-тестов: обработчики Telegram, два языка, изоляция пользователей, плейлисты, отмена, очистка файлов, резерв загрузки, анализ ритма и проекты сетов. Мобильные Chromium/WebKit также проверяют звуковой движок, эффекты, запись и восстановление проекта. Проверки на физических телефонах выполняются отдельно. Инструкции находятся в [английском README](README.md#verification).

Это работающий прототип для портфолио, созданный итеративно с помощью AI. Он не является обещанием круглосуточного публичного сервиса. Платежи и надёжное распознавание напевания пока не реализованы. Музыкальные платные API не включены. Сетка ударов оценивается локально и допускает ручную поправку.

Используйте только материалы, на обработку которых у вас есть разрешение. Закрытые публикации могут быть недоступны; лимит выходного видео — 49 МиБ. Не публикуйте токены, cookies, пользовательские данные и резервные копии.
