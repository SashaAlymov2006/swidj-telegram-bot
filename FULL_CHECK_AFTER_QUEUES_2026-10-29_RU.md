# Повторная проверка SwiDJ после обновления очередей

Дата: 29 октября 2026. Проверяется рабочий образ `swidj:parallel` (код 25cb5a6), бот и Mini App. Функциональных изменений в ходе проверки пока не внесено.

## Что проверено

| Направление | Метод |
|---|---|
| Команды бота, кнопки, выбор версий, повторная загрузка | Изолированные тесты обработчиков и Telegram SDK; без сообщений реальным пользователям |
| Избранное, коллекции, плейлисты, удаление, RU/EN, права администратора | Полный набор автотестов; живые библиотеки проверяются чтением и сравнением |
| Поиск, опечатки, авторы, четыре каталога, чарты | Реальные API Mini App и независимые проверки источников |
| YouTube, SoundCloud, TikTok, Instagram | Полные загрузки тестовых открытых записей через Mini App и отдельно через функции обычного бота |
| Spotify, Apple Music, Яндекс Музыка | Разбор ссылки, выбор записей и полный аудиофайл найденной версии; не выдаётся за прямой оригинальный файл каталога |
| Audius, Jamendo | Поиск и прямые ссылки на разрешённые записи |
| Кэш и резервные пути | Повтор без обращения к источнику, общий кэш чат/приложение, искусственный отказ основного загрузчика только внутри тестового процесса |
| MP3/WAV, эффекты, тон и скорость | Настоящий экспорт на VPS, автотесты аудиопроцессора и действий интерфейса |
| DJ | Анализ, чтение проектов, live loop/roll и запись в тестах AudioWorklet |
| Голос, запись и мелодия beta | Голосовой запрос, известная запись, синтетическое напевание; отсутствие совпадений на синтетике не является отказом API |
| Тексты и видео | Обычный/синхронный текст в интерфейсе; настоящий видеорендер с текстом, пресетами и анимациями |
| Очереди, отмена, ограничение ресурсов | Автотесты и отдельный лёгкий тест трёх сессий на рабочем VPS |

## Границы проверки

Настоящий iPhone/Android в этой сессии не использовался. Тестовые запросы выполняются с VPS, поэтому задержки не отражают мобильную сеть. Проверка загрузок относится к указанным открытым тестовым записям, а не ко всем возможным ссылкам интернета. Работа внешнего сервиса в момент проверки не гарантирует его постоянную доступность.

Проверки не отправляют сообщения Telegram реальным пользователям, не удаляют музыку и не меняют их язык или коллекции. Нагрузочный тест использует отдельные подписанные тестовые идентификаторы. Для сохранения отзывчивости тяжёлые этапы выполняются по очереди; нагрузочный замер запускается отдельно от остальных аудитов.

Результаты и исходные журналы сохраняются в Downloads/SwiDJ-verification/2026-10-29-after-queues.

## Результаты функциональной проверки

- Повторно прошли 399 тестов основного проекта, 24 теста видеостудии и 18 JavaScript-тестов. Дополнительно прошли семь сценариев выбора источника/версии в интерфейсе. GitHub Actions для кода 25cb5a6 завершился успешно.
- Все восемь сценариев основных ссылок проверены через API Mini App. Для Spotify/Apple/Яндекс получены по пять вариантов, а выбранные полные записи имеют длительность 263,26 / 263,26 / 207,26 секунды. Файлы остальных платформ доступны с HTTP Range 206.
- Отдельно функции обычного бота полностью скачали аудио YouTube, SoundCloud, Spotify/Apple/Яндекс, Audius и Jamendo, видео TikTok/Instagram и слайд-шоу TikTok. Холодные загрузки выполнялись в изолированном тестовом кэше.
- Независимый поиск YouTube/SoundCloud/Audius прошёл. Jamendo при первом запросе `piano` вернул пустой список. Прямая ссылка при этом работала; последующие проверки точного названия и исходного `piano` дали по три проверенные версии (1,30 и 1,21 секунды). Точная причина первого пустого ответа не доказана. Он сохранён в исходном журнале и не скрывается успешным повтором.
- Голосовой запрос в Mini App распознан и нашёл пять результатов. Голосовой распознаватель обычного бота также вернул текст. Известная музыкальная запись распознана AcoustID с двумя совпадениями. Синтетическое напевание длительностью 21 секунду обработано без ошибки, но совпадений нет: функция остаётся beta, это не доказательство распознавания любого напевания.
- Все 29 закэшированных треков двух коллекций доступны для потокового воспроизведения. Ещё одна сохранённая запись не имеет готового файла в кэше. Списки коллекций и языки остались прежними.
- Проверены поиск с опечатками, каталог исполнителя, свежие чарты DE/GB/US, выбор пяти версий из чартов, тексты песен, DJ-анализ и проекты, MP3/WAV с 15 эффектами в двух наборах, независимый и совместный тон/скорость, целостность баз.
- Проверка искусственного отказа основного загрузчика затрагивала только тестовый процесс. Резерв SoundCloud вернул полный аудиофайл, видеорезерв бота и Mini App — ролик в 720p. Проверено повторное получение из кэша без обращения к источнику и использование одного кэша ботом и приложением.
- Настоящий экспорт видео: 18 пресетов, H264/AAC 1080p60, HTTP 206, библиотека отвечает во время рендера. Отдельный экспорт с анимацией и синхронным текстом получил 59 строк LRCLIB и завершился успешно. Также загружен файл 1920×1080 размером 109 436 126 байт.
- Первый запуск изолированных серверных автотестов имел ошибку пути к тестовым исходникам. Путь исправлен, полный повтор — 399/399. Рабочий контейнер и пользовательские файлы эта ошибка не затрагивала.

## Небольшая нагрузка: три сессии

За 90,135 секунды выполнено 427 HTTP-запросов: 157 ответов 200 и 270 ответов 206. Отказов 429, сетевых и серверных ошибок нет. Все три поиска, три импорта из кэша, три холодных загрузчика обычного бота, три аудиорендера и три видеорендера завершились успешно.

- Поиски: 10,9–19,9 секунды с ожиданием и внешними каталогами.
- Импорт сохранённого трека: 0,026–0,049 секунды; это не оценка скорости холодного источника.
- Три холодные загрузки SoundCloud: 3,77–3,82 секунды, полные файлы по 5 135 397 байт.
- Приём 45-секундного WAV с четырьмя эффектами: 0,034–0,041 секунды; все задачи затем готовы.
- Три двухсекундных видео 1080p30: 6,1–17,6 секунды с последовательным рендером.
- Во время аудиообработки CPU всего VPS достигал 42,9%, видеорендера — 39,8%. Короткий общий пик 86,5% пришёлся на холодные загрузки, затем нагрузка снизилась.
- Пик памяти контейнера бота вместе с клиентом проверки: 0,615 GiB; видеосервиса — 305,5 MiB. Доступная память VPS не опускалась ниже 13,10 GiB. Это не оценка расхода при одновременном распознавании нескольких длинных записей.

Дополнительные проверки двух публичных Instagram-видео прошли и для видео, и для аудио. Маленькое YouTube-видео прошло через обычный загрузчик бота и API Mini App; резерв в этих двух проверках не использовался.

В свежих журналах основного контейнера не обнаружены ERROR/Traceback/Conflict. Время запуска контейнера не изменилось: 2026-10-29T15:53:05.406404281Z. Бот не перезапускался. Функциональных изменений не внесено; исправлены только подписи графика проверки, чтобы он показывал действительные три сессии и длительность.

Итог: проверенные сценарии работают после обновления, в том числе под небольшой нагрузкой. Два первоначальных отклонения — пустой поиск Jamendo и проверка свежести нескольких чартов — сохранены в отчёте; повторы успешны. Нет оснований обещать отсутствие будущих ограничений внешних сервисов.


Уточнение после итоговой сверки всех журналов: первая групповая проверка чартов DE/GB/US также завершилась AssertionError спустя 31,98 секунды. Это была проверка непустого результата и признака свежести; детальное состояние страны в первоначальном ответе не сохранено. Последующая отдельная проверка всех шести стран DE/US/GB/FR/UA/RU прошла: везде по 50 треков, `stale=false`, британский чарт обновлён в 16:14:52 UTC. Первоначальный журнал сохранён. Таким образом, было два первоначальных отклонения, оба не воспроизвелись при повторе. Работа внешних каталогов может быть нестабильной; это не следует выдавать за безусловное отсутствие сбоев.
