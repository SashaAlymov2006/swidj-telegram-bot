# Configuration and privacy

- Keep tokens and cookies in private environment configuration.
- This repository contains synthetic test identities, not a runtime user database.
- Owner access is denied unless OWNER_USER_IDS explicitly authorizes the user.
- Run one polling process per token.
- Persistent volumes contain user state and uploaded media; manage access and retention accordingly.
- Backup archives may contain private runtime data and must not be uploaded to GitHub.
- Use only media you are authorized to retrieve or process.

If a credential is accidentally published, revoke it with its provider before removing it from history.
