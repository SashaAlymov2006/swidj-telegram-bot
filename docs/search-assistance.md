# Approximate music search

Shared search assistance runs in bot Genius/Deezer metadata lookup and in Mini App/recording lookup for all four music providers. Original requests remain first. Exact title, artist or combined identity preserves original results without an additional lookup. Existing catalog engines handle spelling errors; local token similarity boosts close results. Cyrillic phonetic hints and likely wrong keyboard layout can trigger at most two additional requests per provider, stopping on a relevant result. Weak originals remain available if alternatives fail or do not match. Cancellation and download eligibility checks remain.

The helper combines general Cyrillic transliteration with a small multilingual phonetic vocabulary, covering common English, German, French, Italian and Spanish forms. This is bounded assistance, not a universal phonetic recognizer or Google-scale spelling model. Coverage depends on provider metadata and search. Short ambiguous requests cannot identify a unique song. No paid API, new account, audio recognition model or automatic translation service was added. Query alternatives can increase latency on weak searches; exact searches bypass them. Normal catalog, download, video reserve, studio and library functionality is retained.

Tests cover exact Russian/foreign titles, typos, both keyboard directions, multilingual phonetic examples, accents/apostrophes, unrelated matches, fallback errors, original result preservation, shared bot/source lookup, and authenticated RU/EN Mini App search cache/library isolation. Physical phone testing is not implied.
